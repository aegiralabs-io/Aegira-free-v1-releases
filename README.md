# Aegira Free — Releases

This repository hosts **binaries only**. Source code is in a private repository.

## Download

Latest release: [Releases page](https://github.com/aegiralabs-io/Aegira-free-v1-releases/releases/latest)

## Install

```bash
wget https://github.com/aegiralabs-io/Aegira-free-v1-releases/releases/latest/download/aegira-free-v1.0.4-x86_64.tar.gz
tar -xzf aegira-free-v1.0.4-x86_64.tar.gz
sudo ./install.sh
```
