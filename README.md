# Aegira Free — Releases

This repository hosts **binaries only**. Source code is in a private repository.

## Install

```bash
wget https://github.com/talatsajafa/Aegira-free-v1-releases/releases/latest/download/aegira-free-x86_64.tar.gz
tar -xzf aegira-free-v1.0.0-x86_64.tar.gz
sudo ./install.sh
```
## What is Aegira?
Automated recovery for Linux services and containers.
